Ajustes

Privacidad

CyberLens guarda contadores, categorías, confianza y nombre de página. Nunca guarda el texto analizado.

Idioma

El idioma cambia la interfaz. El modelo NLP actual sigue trabajando con el dataset entrenado del proyecto.

Tema de color

Los mismos temas que el chatbot de demostración. El cambio se guarda automáticamente.

Servidor local

Para analizar contenido debes tener la API activa en localhost:8000.

Datos por página

Las estadísticas se agrupan por hostname, por ejemplo X, WhatsApp Web, LinkedIn o cualquier página detectada.
